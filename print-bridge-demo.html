使用说明

测试前先确认

  • 先启动桌面端程序，确认本地桥服务已经监听在 127.0.0.1。
  • 把桌面端界面中的 access token 粘贴到上面的 token 输入框。
  • 把当前页面的 Origin 加到桌面端配置里的 allowed origins 中。
  • 如果你是用 file:// 打开本文件，浏览器可能会发送 Origin: null。
  • 如果走本地静态服务，记得把类似 http://127.0.0.1:5500 加进白名单。
  • 当前桥服务只支持 PDF 打印链路。
  • 现在支持两种测试方式：网络 PDF 地址，或直接选择本地 PDF 文件。
  • 当前版本会直接弹 Windows 系统打印对话框，不再依赖 SumatraPDF。
